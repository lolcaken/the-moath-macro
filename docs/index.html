What's in the box

Six systems, one window.

Auto fish

Casts on a loop, holds for a perfect cast, watches the reel bar and lands the catch. Calibrated per rod, tuned by balance boost, with a jittered timing profile so a session doesn't read like a metronome.

Four minigames

Lullaby, Maelstrom, Noiseform and Pinions Aria each get a controller that reads the bar from memory and drives the cursor, not a screenshot guess.

Fish ESP

An always-on-top window marks every roaming fish with a bracket box, name, rarity and distance. Rarity filters, tracers, edge arrows, per-tier colours.

Relic ESP

Relics roam like fish, so they get their own card, switch and tier filter. Enchant, Exalted, Cosmic, Twisted, Crested and Empyrean each keep a distinct colour.

Harpoon

Targets by rarity and range, aims the camera with a sampled controller and throws. Runs instead of rod fishing when you want the water cleared.

Updates itself

Checks the release channel on launch, verifies the SHA-256, and installs in place behind an Install button. No re-download ritual.

Architecture

Three processes, one job each.

  1. 01

    The shell

    Chimera.exe holds the UI, writes the config and spawns the core. Tauri window, no browser chrome.

  2. 02

    The core

    ChimeraCore.exe attaches to Roblox read-only, runs the Lua modules, resolves offsets, and keeps the overlay alive. Crash here and the game never notices.

  3. 03

    The overlay

    ChimeraOverlay.exe owns a click-through DirectComposition window over the client. 60 fps, per-pixel alpha, F8 to hide.

The core opens Roblox with PROCESS_VM_READ and nothing else — no writes, no injection, no DLLs in the game. Input is synthesised the way a keyboard does it.

Before you download

Short answers.

Where should I download it from?

This page, or the GitHub releases page it links to. Builds posted anywhere else are not ours and may carry anything. Check the SHA-256 above against the file you get.

Does it inject into Roblox?

No. The core reads memory, the overlay draws in its own window, and the macro sends input. Nothing is loaded into the game process.

Why did my install lose the ESP after updating?

That was 1.1.9 and 1.1.10 — the archive shipped without ChimeraOverlay.exe. Fixed in 1.1.11: the packaging step refuses to build an archive missing the overlay, the core reports the overlay state on the Visuals card, and it relaunches the overlay if the process dies.

Does it work with every rod and minigame?

Rod and minigame controllers are calibrated per rod. The four shipped minigames cover the common rods; anything new needs a calibration pass, which is what the Calibration card is for.

Windows SmartScreen says unknown publisher.

The build is not code-signed. Choose More info → Run anyway. The checksum is published so you can confirm the file before you run it.
